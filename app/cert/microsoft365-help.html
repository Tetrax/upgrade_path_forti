Comment configurer Microsoft 365 ?

FortiUpgrade peut envoyer les notifications sans serveur SMTP, depuis une boîte Microsoft 365 autorisée.

Le bouton de test envoie réellement un message avec la configuration enregistrée. Une réponse HTTP 202 confirme l’acceptation par Microsoft Graph, pas la remise dans la boîte du destinataire.

Saisir ou remplacer le Client Secret

Dans Administration → Notifications → Microsoft 365 / Azure, collez la Value du secret Entra (pas son Secret ID) dans le champ masqué, puis cliquez sur Enregistrer / remplacer le secret. La valeur reste dans un fichier privé persistant : elle n’est jamais renvoyée à l’interface. Cette action ne change pas le transport et n’envoie pas de mail.

Si le stockage est indisponible, mettez à jour l’image et le Stack comme indiqué dans le guide. Les installations Docker/Portainer, dont les VM avec image importée, utilisent le même volume privé dédié ; aucun helper spécifique au VPS n’est nécessaire.
